# Kartheek Portfolio

This is a simple GitHub Pages personal portfolio site.

## What to edit

- In `index.html`, replace `your.email@example.com` with your email address.
- Your GitHub profile link is already set to `https://github.com/TechyAnand`.
- Update the project cards with your real projects, achievements, or certifications.
- Edit the summary text so it matches your exact background.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and this `README.md`.
3. Open the repository on GitHub.
4. Go to `Settings` > `Pages`.
5. Under `Build and deployment`, choose `Deploy from a branch`.
6. Select the `main` branch and `/root`, then save.

Your page will be available at:

```text
https://TechyAnand.github.io/REPOSITORY-NAME/
```

For a personal homepage, name the repository:

```text
TechyAnand.github.io
```

Then your page will be available at:

```text
https://TechyAnand.github.io/
```
